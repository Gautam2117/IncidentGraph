# ADR-000: Use Architectural Decision Records

## Context
IncidentGraph is a production-style agentic incident investigation and evaluation platform. Complex architectural choices need transparent, defensible records for engineering quality and interview review.

## Decision
We record all architectural decisions in markdown files under `docs/adrs/` using the standard Michael Nygard format.

## Status
Accepted

## Consequences
- Every significant system boundary, technology choice, or protocol design is documented.
- Architecture choices are traceable to specific PRD and validation criteria.
